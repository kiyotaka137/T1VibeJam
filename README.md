# 🧠 LLM Service for Auto-Testing System

Этот микросервис отвечает за "интеллект" нашей системы. Мы используем модель **Qwen-32B** (через API SciBox) для двух сценариев:
1. Генерация алгоритмических задач для собеседования.
2. Умный ментор, который дает подсказки по коду, но не палит решение.

## 📂 Структура проекта

```text
.
├── main.py                 # Скрипт для проверки/тестирования работы (Запускать из корня!)
├── src/
│   ├── prompts/            # Текстовые промпты (системные инструкции, шаблоны)
│   └── services/           # Логика работы с LLM (LangChain, парсинг JSON)
│       ├── task_generator.py
│       └── hint_generator.py
````

## 🛠 API и Сценарии использования

### 1️⃣ Сценарий: Генерация Задач (`TaskGenerator`)

Генерирует 3 задачи по заданной теме и уровню сложности.

  * **Класс:** `src.services.task_generator.TaskGenerator`
  * **Метод:** `generate_tasks(grade: str, topic: str)`

**Входные данные:**

  * `grade` (str): Уровень кандидата (например: "Junior", "Middle", "Senior").
  * `topic` (str): Тема задач (например: "Arrays", "Binary Search", "DP").

**Возвращает (JSON dict):**

```json
{
  "task1": "Текст условия первой задачи...",
  "task2": "Текст условия второй задачи...",
  "task3": "Текст условия третьей задачи..."
}
```

-----

### 2️⃣ Сценарий: Ментор / Подсказки (`HintGenerator`)

Анализирует код пользователя и историю чата, находит ошибку и дает наводку.
**Важно:** Модель настроена так, чтобы **НИКОГДА** не писать готовый код решения.

  * **Класс:** `src.services.hint_generator.HintGenerator`
  * **Метод:** `generate_hint(user_code: str, chat_history: str)`

**Входные данные:**

  * `user_code` (str): Текущий код решения пользователя (с ошибками).
  * `chat_history` (str): Вся история переписки в виде строки (User: ..., Assistant: ...).

**Возвращает (JSON dict):**

```json
{
  "hint": "Текст подсказки. Например: 'Обратите внимание на условие выхода из цикла...'"
}
```
> **Note:** Модель использует режим **Reasoning** (цепочка рассуждений) для поиска ошибок, но в финальный ответ попадает только чистый JSON.
